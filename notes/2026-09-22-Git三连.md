## 用快递理解三个命令

1. `git add` —— **打包**：把改动的文件放进包裹（暂存区）。
2. `git commit` —— **装箱贴单**：给包裹拍一张快照，写清楚这次改了什么。
3. `git push` —— **寄出**：把包裹送到 GitHub 仓库。

## 今天实际敲过的命令

```bash
git add index.html
git commit -m "Day 2｜完成第一个网页占位页"
git push origin main
```

## 踩过的一个坑

`commit` 之前忘了 `add`，结果提交里什么都没有。记住口诀：**先打包，再贴单，最后寄出**。
