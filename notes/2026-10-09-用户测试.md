- **我自己为什么没发现**：今天想清楚了，有三个原因，一个比一个根本——

### 原因 1：知道答案的人，看不见问题

这个链接是我自己加上去的。我"看"页面的时候，看到的不是屏幕上的像素，而是我心里的设计意图——「这里有入口，点它能进详情页」。
可陌生人看到的只有一行蓝色小字，夹在另一行灰色小字下面。**作者视角的「显然」，就是用户视角的「不存在」。**

### 原因 2：我的自测脚本测错了维度

Day 13 的 `day13-views-test.cjs` 有 **32 项断言，全部通过**。但今天回头看，那 32 项测的全是**功能性**：

- 点了能不能跳转 ✅
- 地址栏对不对 ✅
- 前进后退灵不灵 ✅

**没有一条在问「这个东西用户看得见吗」。** 功能全对、可见性全错、测试全绿——这大概是最危险的一种绿灯。

**可用性（好不好用）和功能性（能不能用）是两件事**，而我之前只测了后者。能用的东西不一定好用。

### 原因 3：我在测「我做的对不对」，而不是「用户过的顺不顺」

前两天的自测脚本，本质是在验证"我的实现符合我的设计"。这是**向内**的检查。
用户测试是**向外**的：不看设计意图，只看屏幕上有什么。两者不可互相替代。

## 今天做了什么

### ① 先给真人测试打前站：机器走查（`day14-walkthrough.cjs`）

真人要等，但有些卡点是**机械可测**的——比如"入口是不是压根没被摆到看得见的地方"。
所以先写了个脚本，模拟一个**完全不看说明的陌生人**，检查每个"该被发现"的入口：

- 它在不在第一屏里（不滚动能不能看到）？
- 它长得像不像"能点的东西"？
- 它够不够大，手机上点得中吗？

**结果：0 项机械硬伤**（站名、导航、标签、详情入口都在第一屏内），
但**揪出 3 个同源卡点**，全部指向卡片底部的「打开独立页面 →」：

| # | 问题 | 实测数据 |
|---|---|---|
| 1 | 没有下划线，只靠蓝色区分 | `text-decoration: none`，违反 WCAG 1.4.1（不能只靠颜色传达信息） |
| 2 | 和上方「▼ 展开全文」看成一类 | 同为 13px，文字之间只隔 6px；一个能点、一个不能点 |
| 3 | 点击区太小 | 95 × 22px，手机建议 ≥44px |

### ② 最小修复：只改这一个元素

`style.css` 里 `.note-open-link` 一条规则：补下划线（`text-decoration: underline`）+ 撑大点击区（`padding`，同时用负 `margin` 让文字左边缘位置不变）。

**复测（`day14-walkthrough.cjs` 重跑）**：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 下划线 | 无 | **有** ✅ |
| 与上方提示的文字间距 | 6px | **17px** ✅ |
| 点击区 | 95 × 22px | **115 × 44px** ✅ |
| 疑似卡点 | 3 项 | **0 项** ✅ |

只动这一处——真人的其他反馈等测试回来再改，**不做"一口气全改"**。

## 今天踩的坑

### 走查脚本的判据，不能把"观察值"写死成字面量

第一版脚本里，「两行小字会不会看成一类」这条我写的是：

```js
sameLook ? "都是 " + hint.fontSize + "，且紧挨着（间距 6px）" : "字号已区分"
```

那个「间距 6px」是我**量了一次之后手写进字符串的**。结果修复完（间距变成 17px）脚本还在报「间距 6px」——**假警报**。

教训和 Day 13 那个「等 `.state-box` 出现」的坑是同一类：**判据必须是现场实测出来的，不能是记忆或复制粘贴**。

改法：改成真的去量两个元素之间的文字距离：

```js
const visualGap = Math.round((openLink.top + openLink.paddingTop) - hint.bottom);
```

顺带还发现一个细节：间距要按"**文字之间**的距离"算，不能按"**盒子之间**"的距离算——
链接加了内边距后，两个盒子几乎贴在一起，但文字其实已经隔开了 17px。量错了就会得出相反的结论。

## 真人测试 vs 机器走查：两者测的不是一回事

| | 机器走查（今天做了） | 真人测试（待做） |
|---|---|---|
| 能测出 | 入口**有没有被摆出来**、够不够大、在不在第一屏 | 用户**以为该怎么用**、心里怎么想的 |
| 测不出 | 心智模型不符 | 覆盖不到的边角 |
| 例子 | 「链接没有下划线，看不出能点」 | 「我以为点卡片就是整篇文章了，没想过还有别的页面」 |

**所以走查不能替代真人测试。** 它只能把"低级的、机械的卡点"提前清掉，
让真人的那次测试能花在更值钱的地方——**心智模型的差距**。
