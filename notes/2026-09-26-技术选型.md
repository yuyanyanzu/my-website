## 最终选定的路线

> 纯 HTML/CSS/原生 JS 单页 + Markdown 文件作数据源 + marked.js 渲染 + GitHub Pages 托管。

## 三个关键取舍

| 选择 | 放弃了谁 | 原因 |
|---|---|---|
| 原生三件套 | Vue / React | 零基础阶段每一行都要看得懂，不引入构建工具链 |
| Markdown 文件当数据源 | 数据库先行 | PRD 已砍掉在线写入，没有写入端就不需要后端 |
| GitHub Pages | 买服务器 | 免费、push 即发布 |

## 一句话记住数据流

我写的笔记通过 `git push` 存进 GitHub 仓库，Pages 把仓库发布成网站，访客浏览器用 JS 拉取并渲染——**数据从我的键盘来，到访客的屏幕上去**。
